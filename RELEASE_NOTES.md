# Release Notes - InstaSaver HD v1.2.0 (Version Code 3)

## 🚀 What's New in Version 1.2.0

### 📲 System "Share To" Menu Integration
- **Direct Share Support**: InstaSaver HD now appears in the system Share sheet when sharing links or text from apps like **Signal**, **WhatsApp**, **Instagram**, **Chrome**, or **X/Twitter**.
- **Smart Link Extraction**: Automatically extracts and sanitizes Instagram URLs even when surrounded by text in chat messages.
- **Auto Fetch on Share**: Opens InstaSaver HD and immediately starts fetching the shared reel/video media preview.
